# Populate

A self-run population sim project, where virtual people ("Dolls") live and die, interact with each other, and have children.

Right now dolls can have a first and last name chosen at random, and a set of "needs" values for hunger, mood, and energy (currently nonfunctional).

# The current version of the program:
- Creates a database with a table for dolls if one doesn't exist.
- Adds 10 dolls with random characteristics to the database.
- Prints out all the dolls currently in the database (including ones from previous executions)
- Dolls needs are formatted as a "status" (e.g. Hungry, Happy, Tired)
